# Vegas Pocket

A pocket guide for a family weekend in Las Vegas, Nov 14 to 17, 2026: finding food, bars and entertainment, getting around, game day at Allegiant Stadium, and getting to the airport on time.

Single-file web app. Everything a visitor saves (hotel choice, saved places, flight time) stays in that phone's local storage. No accounts, no sync, no tracking.

Preview any moment of the trip with `?now=2026-11-15T10:20` (Pacific time).
